Apresentação

Por: Vitória Manuella

Olá, senhoras e senhores, como Monitora de Pensamento Computacional e uma pessoa que gosta muito de programação, trouxe por aqui um breve resumo sobre as 4 principais linguagens de programação. Espero que goste!

HTML

(HyperText Markup Language)

É a estrutura básica de qualquer site. Ele funciona como o "esqueleto" da página, utilizando marcas (chamadas de tags) para organizar e apresentar os elementos na tela.

CSS

(Cascading Style Sheets)

É o responsável pela aparência e estilo do site, funcionando como a "pele" ou a "roupa" do HTML. Com o CSS, você define cores, fontes e tamanhos.

JS

(JavaScript)

É a linguagem de programação que traz interatividade e dinamismo para as páginas web.

PY

(Python)

É uma linguagem de programação genérica, muito popular por sua sintaxe simples e fácil de ler.
